☕ Brew & Bites Café

A modern, professional and responsive café business website built with HTML, CSS and JavaScript.

🌟 About the Project

Brew & Bites is a premium café website designed to give customers a complete digital experience.

Customers can:

* Explore the café
* View the food and drinks menu
* Filter menu items by category
* Add items to an online order
* Place orders through WhatsApp
* Make table reservations
* View the café gallery
* Read customer reviews
* Find the café location
* Contact the business
* Subscribe to special offers

⸻

🚀 Features

🏠 Home

Professional hero section with café branding, promotional content and quick access to the menu and reservations.

☕ Menu

The menu includes:

* Coffee
* Breakfast
* Lunch
* Drinks
* Desserts

Customers can filter items by category and add products to their order.

🛒 Online Ordering

The website includes a shopping cart system.

Customers can:

1. Add products to their cart
2. Increase the quantity of products
3. Remove products
4. View the total price
5. Send the order directly through WhatsApp

📅 Table Reservations

Customers can submit:

* Name
* Phone number
* Date
* Time
* Number of guests
* Occasion
* Special requests

The reservation information can then be sent to the café through WhatsApp.

📸 Gallery

A responsive gallery section allows the café to display:

* Interior photos
* Food
* Coffee
* Desserts
* Events
* Customer experiences

⭐ Customer Reviews

The website includes a customer testimonial section where the café can showcase reviews and ratings.

📍 Location

The contact section includes:

* Café address
* Phone number
* Email
* WhatsApp
* Google Maps directions

📱 Responsive Design

The website is optimized for:

* Mobile phones

🎨 Modern Design

The website uses:

⚙️ Customization

Before publishing the website, replace the example information with the café’s real information.

Café Name

Search for:

BREW & BITES

and replace it with your café name.

Phone Number

Replace:

255700000000

with the café’s WhatsApp number.

Address

Replace:

Masaki, Dar es Salaam, Tanzania

with the actual café address.

Email

Replace:

hello@brewandbites.com

with the café’s official email.

Images

Place the café’s real images inside:

images/

Make sure the filenames match the names used in index.html.

🌐 Deploy on GitHub Pages

1. Create a Repository

Create a new repository on GitHub.

Example:

brew-and-bites

2. Upload the Files

Upload:

index.html
README.md
images/

3. Open Repository Settings

Go to:

Settings → Pages

4. Select Deployment Source

Choose:

Deploy from a branch

Then select:

Branch: main
Folder: /root

Click Save.

5. Open Your Website

GitHub will generate a website address for your repository.

Your café website will then be available online through GitHub Pages.
